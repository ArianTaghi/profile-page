# مقالات قیزیلچی

صفحهٔ فهرست در `/ghizilchi/articles` و آدرس هر مقاله در `/ghizilchi/articles/:slug` قرار دارد. مشخصات و منابع هر مقاله در `articleData.js`، متن‌ها در `content/` و تصاویر WebP در `covers/` هستند. استایل اختصاصی در `../Css/Article/Article.css` از رنگ‌ها و فونت تم پروژه استفاده می‌کند.

برای افزودن مقاله یک فایل Markdown و تصویر اضافه کنید و آن‌ها را در `articleData.js` ثبت کنید. قالب متن از تیتر `##`، پاراگراف، فهرست، جدول، نقل‌قول، متن پررنگ و لینک HTTPS پشتیبانی می‌کند. بین بلوک‌ها یک خط خالی بگذارید. عنوان اصلی از دادهٔ مقاله می‌آید. تصاویر این پنج مقاله برای توضیح موضوع ساخته شده‌اند. تاریخ‌ها تاریخ تدوین نسخهٔ حاضرند و می‌توان آن‌ها را هنگام انتشار به‌روز کرد.

## خروجی HTML برای انتشار

پس از جای‌گذاری `src` در پروژهٔ Vite، بیلد معمول پروژه را بگیرید. سپس از ریشهٔ همان پروژه اجرا کنید و دامنهٔ اصلی را جایگزین کنید:

```bash
npm run build
node src/components/ghizilchi/components/Article/prerender.mjs https://example.com
```

فرمان دوم HTML فهرست و پنج مقاله، عنوان و توضیح هر صفحه، دادهٔ ساختاریافته و `sitemap-articles.xml` را به خروجی Vite اضافه می‌کند. روی میزبان، فایل‌های HTML هر مسیر مقاله را پیش از قاعدهٔ عمومی SPA سرو کنید. برای مثال `/ghizilchi/articles/gold-price` باید به `ghizilchi/articles/gold-price/index.html` برسد. نقشهٔ مقالات را می‌توان در Search Console ثبت کرد یا به فهرست نقشه‌های سایت افزود.

برای ساخت HTML آزمایشی می‌توانید فرمان دوم را بدون دامنه اجرا کنید. نقشهٔ سایت و نشانی‌های مطلق در خروجی استاتیک با دامنهٔ انتشار ساخته می‌شوند.
